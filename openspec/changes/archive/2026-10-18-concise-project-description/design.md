## Context

README уже ведёт к локальному примеру. Повторы остаются в architecture, usage,
package docstrings и записях о поставках. Source layout и runtime менять не требуется.

## Goals / Non-Goals

Читатель должен понять поток данных, найти исполняемый пример и увидеть существенные
ограничения без чтения хронологии разработки. Архитектура и алгоритмы сохраняются.

## Decisions

- Architecture объясняет владельцев, композицию и инварианты; точные дополнительные
  форматы и acceptance matrices остаются в существующих specs.
- README содержит вход в проект, usage — команды, CONTRIBUTING — разработку и
  публикационную ветку, development — проверенную готовность.
- Удаляются package docstrings, повторяющие имя каталога. Комментарии о причинах
  проверки, численных границах, сохранности данных и внешних протоколах остаются.
- Публикационная ветка имеет отдельную историю. Обычный push обновляет только её;
  расхождение историй разбирается до push без автоматического force.

## Risks / Trade-offs

При сокращении можно потерять полезное ограничение или испортить команду.
Проверяем ссылки, исполняемые примеры и неизменность AST без docstrings, YAML-данных
и notebook code cells. Файлы не перемещаются и не удаляются.
